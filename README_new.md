## 📖 Description
**Enchantments Encore** adds **130+ new enchantments** to the game, and you can get them in all the usual vanilla ways: from the Enchanting Table, in loot chests or by trading with Villagers. Mobs can even spawn wearing gear with some of the new enchantments!

The data pack also adds a unique structure, the **Rise**, which always contains a guaranteed enchantment from this data pack.

<br>

## 🔎 Content Overview (Wiki)
Want to know what an enchantment does, which items it applies to or where to find it? It's all in our **[Wiki](https://wiki.explorerseden.eu/en/enchantments_encore/home)**:
- ✨ **Enchantments**: effects, applicable items and loot sources for every enchantment
- 🏛️ **Structures**: what the Rise looks like and what you can find there

Already in game? Check any enchantment you don't know yet in the **in-game wiki**, available from the pause menu.

<br>

## 🤝 Compatibility
- Works with all **vanilla enchantments**, as well as **[NeoEnchant+](https://modrinth.com/datapack/neoenchant)** and the enchantments from **[Katters Structures](https://modrinth.com/datapack/katters-structures)**.
- Other enchantment data packs will most likely work too, but they won't have mutual exclusivities with Enchantments Encore's enchantments.
- Supports **[Enchantment Lore](https://modrinth.com/mod/enchantment-lore)**. If you use the data pack version, make sure to load it as a resource pack as well.
- **n1trus** made an awesome resource pack addon that's fully compatible: **[Bray & Cyber's 3D Books - Enchantments Encore Patch](https://modrinth.com/resourcepack/bray-cybers-3d-books-enchantments-encore-patch)**

<br>

## 🛠️ Technical Gibberish
This data pack works out of the box and also works as the **required** resource pack, which provides the translations and makes the new enchantments stand out from the vanilla ones. Just put the same file into your `resourcepacks` folder and enable it in game.

_(Not needed for the auto-converted mod versions in Single-Player.)_

**PaperMC users:** enable `allow-non-player-entities-on-scoreboards` in your Paper config so everything works properly.
